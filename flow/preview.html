    participant Client
    participant MW as Middleware
    participant H as User Handler
    participant S as User Service
    participant R as User Repository
    participant DB as MainDbConn

    note over Client, DB: Create User Flow
    Client->>MW: POST /users (Bearer Token)
    MW->>MW: Check Permissions (Create)
    MW->>H: CreateUser(Ctx)
    H->>S: CreateUser(user)
    S->>R: CreateUser(user)
    R->>DB: INSERT INTO users ...
    DB-->>R: Result
    R-->>S: nil
    S-->>H: nil
    H-->>Client: 201 Created

    note over Client, DB: Get Me
    Client->>MW: GET /users/me
    MW->>MW: Check Permissions (Me)
    MW->>H: GetMe(Ctx)
    H->>H: Locals("user_id")
    H->>S: GetUser(id)
    S->>R: GetUser(id)
    R->>DB: Select
    DB-->>R: User
    R-->>S: User
    S-->>H: User
    H-->>Client: 200 OK

    note over Client, DB: Get User By ID
    Client->>MW: GET /users/:id
    MW->>MW: Check Permissions (Read)
    MW->>H: GetUser(Ctx)
    H->>S: GetUser(id)
    S->>R: GetUser(id)
    R->>DB: Select
    DB-->>R: User
    R-->>S: User
    S-->>H: User
    H-->>Client: 200 OK

    note over Client, DB: Get Users (List)
    Client->>MW: GET /users?page=...

    H-->>Client: 200 OK
